# Project 2 – Sales Data Analysis

## Overview
This project focuses on exploratory data analysis (EDA) for a sales dataset.  
It includes data cleaning, statistical summaries, visualizations (histograms, boxplots, heatmaps), and an executive summary with findings and recommendations.

## Repository Structure
- `projet2.py` for Python script containing all cleaning and analysis steps.  
- `images/` for Folder with analysis images (histograms, boxplots, heatmaps).  
- `Executive_Summary.txt` for Short report summarizing the results.  
- `Dataset_for_Data_Analytics.xlsx` for Input dataset (not included if large or sensitive; place it in the project folder before running the script).
